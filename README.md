- 은혜한인교회 비전센터 본당

홈페이지의 오른쪽 하단 ‘영상 관리’ 버튼, 관리 페이지, 관리자 로그인 기능을 제거했습니다. 이전 `/admin` 주소는 홈페이지로 돌아갑니다. 유튜브 링크는 저장소의 **videos.json** 파일에 입력합니다. 비밀번호나 별도 저장소 설정은 필요하지 않습니다.

## 생방송 버튼과 깜박임 설정

방송 중으로 설정한 경우에만 행사 날짜·시간 바로 아래에 빨간색 **생방송 보기** 버튼이 나타납니다. 평소에는 버튼과 버튼 영역을 숨깁니다. 버튼을 누르면 아래 유튜브 생방송 주소가 새 창에서 열립니다.

**https://www.youtube.com/GKCTV/live**

GitHub에서 **live.json**을 열어 아래 두 항목을 수정할 수 있습니다.

```json
{
  "url": "https://www.youtube.com/GKCTV/live",
  "isLive": false
}
```

- `url`: 생방송 버튼에 연결할 유튜브 주소입니다.
- `isLive: false`: 방송 전·후 상태입니다. 생방송 버튼이 완전히 숨겨집니다.
- `isLive: true`: 방송 중 상태입니다. 빨간 버튼이 나타나며, **생방송 중** 문구와 함께 배경이 부드럽게 깜박입니다.

**방송 시작 시 `false`를 `true`로 바꾸고 저장하며, 방송 종료 후 다시 `false`로 바꿔 주세요.** `true`와 `false`에는 따옴표를 넣지 않습니다. 연결된 Vercel 배포가 완료되면 반영됩니다. 이미 열어 둔 홈페이지도 1분 간격으로 설정을 확인하며, 방송 종료 설정이 반영되면 버튼을 숨깁니다. 설정을 불러오지 못한 경우에도 버튼을 숨깁니다.

유튜브의 실제 방송 여부를 자동 감지하는 기능은 아닙니다. 날짜가 되었다고 자동으로 방송 중이라고 표시하지 않습니다. 기기에서 ‘동작 줄이기’를 사용하면 깜박임 대신 빨간 버튼과 **생방송 중** 문구로 표시합니다. 영상 관리 페이지는 계속 없는 상태입니다.

## 유튜브 링크 등록하기

1. GitHub 저장소에서 **videos.json** 파일을 엽니다.
2. 연필 아이콘 **Edit this file**을 누릅니다.
3. 등록할 영상 항목을 찾아 `"url": ""`의 빈 따옴표 안에 유튜브 주소를 붙여넣습니다.
4. 필요하면 `name`에 참가팀 이름, `song`에 찬양곡 또는 설명을 입력합니다.
5. **Commit changes**로 저장합니다. Vercel이 해당 브랜치에 연결되어 있으면 자동으로 다시 배포됩니다.

예를 들어 아래 항목의 `url` 빈칸을 실제 유튜브 주소로 채우세요.

```json
{
  "id": "g1",
  "name": "1그룹",
  "song": "",
  "url": ""
}
```

이 예시는 한 항목의 모양입니다. 기존 파일의 해당 항목만 수정하고, 나머지 항목과 쉼표·따옴표는 유지하세요. `id`는 변경하지 마세요.

| 항목 | id |
| --- | --- |
| 1~28그룹 | g1~g28 |
| EM | em |
| GMI 은혜교회 | gmi |
| 성가제 전체 영상 | full |
| Shorts 1~5 | s1~s5 |

일반 YouTube 주소, youtu.be 공유 주소, Shorts 주소, live 주소를 지원합니다. 링크를 빈 문자열로 두면 ‘영상 준비 중’으로 표시됩니다. JSON 문법 오류, 빠진 항목, 중복 id 또는 잘못된 유튜브 주소가 있으면 배포 빌드가 중단되므로 수정한 내용을 다시 확인하세요.

영상은 유튜브에서 공개 또는 일부 공개로 설정하고 외부 사이트 재생을 허용해 주세요. 홈페이지 플레이어의 ‘YouTube에서 보기’로 유튜브에서도 열 수 있습니다.

## 이번 수정만 적용하기

직전 오후 2시 30분 버전을 사용하고 계시면 **src/page.html**, **src/app.js**, **README.md** 세 파일만 같은 위치에 교체해 주세요. 기존 `videos.json`과 `live.json` 설정은 유지하시면 됩니다.

## 기존 GitHub 파일 교체

1. 이 ZIP 파일을 압축 해제합니다.
2. GitHub 저장소에서 기존 `package.json`이 있는 위치로 이동합니다.
3. **Add file → Upload files**에서 압축을 푼 내용물 전체를 올립니다.
4. **Commit changes**를 눌러 저장합니다.

이미 `videos.json`에 영상 링크를 입력하셨다면, 해당 파일은 기존 것을 유지하세요. 이번 변경은 생방송 버튼에만 적용되며 기존 영상 링크를 다시 입력할 필요가 없습니다.

기존 파일과 경로가 일치하도록 올려 주세요. 특히 `src`, `lib`, `api`, `scripts`, `vercel.json`, `package.json`, `package-lock.json`, `videos.json`, `live.json`이 함께 업데이트되어야 합니다. `api/router.js`, `lib/auth.js`, `lib/store.js`는 이전 관리 기능이 남지 않게 교체하는 호환 파일입니다.

## Vercel 배포 설정

- Framework: Other
- Install Command: `npm ci`
- Build Command: `npm run build`
- Output Directory: `public`
- Node.js: 22 이상

별도 외부 저장소나 관리자 환경 변수 없이 작동합니다. 이전 버전의 저장소에 입력했던 링크가 있다면 이번 버전의 `videos.json`에 옮겨 주세요. 이전 버전의 환경 변수는 이 코드에서 사용하지 않습니다.

## 로컬 미리보기

```sh
npm ci
npm test
npm run build
npm run dev
```

실행 후 `http://localhost:3000`에서 확인합니다. `videos.json` 또는 `live.json`을 수정한 뒤 `npm run build`를 실행하면 미리보기에도 반영됩니다.
